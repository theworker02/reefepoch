# reefepoch

Reef CSV/TSV epoch tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/reefepoch/

## Install / run

```bash
git clone https://github.com/theworker02/reefepoch.git
cd reefepoch
node src/cli.js
node --test
```
